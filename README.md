# InsightBoard

O **InsightBoard** é um dashboard em estilo SaaS desenvolvido para portfólio, com foco em **React**, **UI/UX**, **componentização**, **responsividade** e **animações**.

A proposta do projeto foi construir uma interface com aparência de produto real, simulando um ambiente de gestão de requests com visual moderno, navegação entre páginas e visualização de métricas.

---

## Preview

O projeto apresenta:

- dashboard com métricas principais
- gráficos de acompanhamento e distribuição
- navegação entre páginas com React Router
- menu lateral responsivo
- cards interativos com animações
- interface escura com estética moderna
- estrutura pensada para evolução futura

---

## Tecnologias utilizadas

- **React**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **React Router DOM**
- **Recharts**
- **Lucide React**

---

## Funcionalidades

### Dashboard
- visão geral com indicadores principais
- gráficos de tendência mensal
- distribuição por status
- listagem de requests recentes
- busca e filtro por status

### Requests
- visualização completa das solicitações
- busca por título, ID e responsável
- filtros rápidos
- cards com progresso e prioridade

### Analytics
- métricas de performance
- gráficos analíticos
- insights operacionais
- resumo de indicadores

### Settings
- tela de preferências visuais
- configurações simuladas
- área de perfil profissional

---

## Objetivo do projeto

Este projeto foi desenvolvido como peça de portfólio para reforçar minhas habilidades em front-end, com foco em:

- construção de interfaces modernas
- organização de componentes
- navegação entre páginas
- experiência visual refinada
- aplicação prática de React em um contexto próximo de produto real
